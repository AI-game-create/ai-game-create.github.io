なげなわコメット

しっぽで敵をぐるっと囲むと捕まえられます。
まとめて囲むほど得点が何倍にもなります。

かけら 0 個 ・ 強化はずっと残ります

タップ / クリック / P キーで再開します

操作:マウスを動かす / 画面をなぞる / 矢印キー・WASD で、ほうき星が動きます。 しっぽが自分と交差すると輪になり、中にいる敵を捕まえます。
ルール:ウェーブには制限時間があり、過ぎると敵が残ったまま次のウェーブが来ます。ピンクのトゲトゲと赤い弾にさわるとハートが減ります。オレンジのカッターにしっぽを横切られると輪が消えます。 5ウェーブごとにボスが出ます。ボスは何度か囲まないと捕まりません。
スコア:1回の輪で捕まえた数がそのまま倍率になります(3体なら3倍)。ボスの弾も輪で消せます。
リトライ:ゲームオーバーになると、スコアに応じて「かけら」がもらえます。かけらでほうき星を強化して、もう一度挑戦しましょう。強化はこのブラウザに保存されます。
その他:P / Esc で一時停止、M で音のオン・オフ。
