# 設計書: 凍原の犬ぞり便(2026-10-11 公開)

## ひとことで
6頭の犬ぞりで、日暮れの森から夜の凍原を越えて、嵐が来る前に北の鉱山村へ荷(薬・郵便・灯油の6箱)を届ける。
リアル調の3D(WebGL2・HDR・夕日の影・月明かり・オーロラ・吹雪・ヘッドランプ)。
今週の「苦手に挑戦」は**走る犬**。6頭の体・脚の運び(トロットと駆け足)・息・しっぽを、できる限り本気で作る。

- 進み方の形: **ひと続きの長い旅**(区切りなし。森 → 分かれ道 → 湖か岸 → 夜の森と小屋 → 峠か川 → 吹雪 → 村)
- 直近3作は「エンドレス」「毎回生まれ変わる」「自由に歩き回る世界」なので、どれとも違う

## 面白さの種類
**判断**(中心)・**腕前**
- 判断: 犬の体力・自分の体温・嵐までの時間の3つを、ペース・道・休みでやりくりする。
  「いま全力で走らせるか、温存するか」「湖を突っ切るか、岸を回るか」「小屋で何秒休むか」「峠を越えるか、川沿いか」
- 腕前: そりは犬の通ったあとを通る(先頭から8m遅れて同じ所を通る)。岩・倒木・氷の割れ目・川の開いた水面を、**先を読んで**よける。
  速く走るほど、よける余裕がなくなり、ぶつかったときに荷が落ちる

## 迷い(考えどころ)
- **ペースは4段**(止まれ / トロット / 駆け足 / 全力)。全力は速いが体力をみるみる使う。体力が尽きると犬は歩くのがやっと。
  上り坂は体力の減りが倍以上。下り坂で全力のままだと、そりが犬に追いついて**追突**する(ブレーキが要る)
- **分かれ道1**: 凍った湖を突っ切る(近道。途中で氷が後ろから割れてくるので、全力で逃げきる体力が要る。薄い氷は速さで渡る)
  / 岸を回る(遠回り。吹きだまりで遅くなる)。**着いた時点の体力**で、正解が変わる
- **小屋**: 止まれば体力と体温が戻るが、そのあいだも嵐は近づく
- **干し魚(2匹)**: いつ食べさせるか(食べている間は少し遅くなる)
- **分かれ道2**: 峠を越える(近いが、きつい上り・山頂の寒風・急な下り)/ 川沿い(遠いが平ら。開いた水面をよける)
- どの判断も、体力・体温・時間のどれかを払う。決まった正解はない

## 腕の差
- 考えて遊んだ人: 平地は駆け足、割れる氷と吹雪の前だけ全力、上りはトロット、下りはブレーキ、体力が残っていれば近道、
  小屋で必要なぶん休む、魚は体力が落ちたときに使う → 荷をほぼ落とさず、吹雪が強くなる前に着く
- 適当に遊んだ人: ずっと全力 → 序盤で体力が尽き、遅くなって吹雪に追いつかれ、凍えて遭難する。または割れた氷に落ちる・下りで追突する
- 物差し: **配達点**(届けた荷 ×100 + 早く着いたぶんの点。遭難は0点)。
  考える自動プレイヤー と「いつも全力」「でたらめ」の自動プレイヤーを、同じ種で3回ずつ遊ばせて平均を比べる(1.5倍以上)

## 変化
- 景色と時間がひと続きで変わる: 夕日の森 → 青い夕暮れ → 月とオーロラの夜 → 雲が広がり吹雪 → 村の灯
- 出来事: 湖の氷が後ろから割れて追ってくる / 薄い氷 / 吹きだまり / 小屋の灯 / 峠の寒風と見晴らし / 急な下り / 川の湯気と開いた水面 / 吹雪で目じるしの杭しか見えない
- 毎回ちがう: 岩・倒木・薄い氷・吹きだまり・開いた水面の場所、氷が割れ始める場所、嵐の来る早さ、風向き
- 選んだ道で、見る景色も危険もまるで違う(4通り)

## もう1回
- 通らなかった道(湖/岸、峠/川)を試したくなる。道の組み合わせごとに最高記録を残す
- 「6箱そろえて特急で着く」を狙いたくなる(結果に、落とした荷とその場所、どこで時間を使ったかを出す)

## 緊張
- 割れる氷に追いつかれそうになる瞬間(後ろで氷が持ち上がり、水しぶきが上がる)
- 下りで、そりが犬に迫る(「押している!」の警告)
- 体温が減っていく吹雪の中、杭を頼りに村の灯を探す
- 失うもの: 荷(落とすと戻らない)、犬のけが(遅くなる)、命(体温が尽きると遭難)
